# C-001：tiny-todo HTTP 接口与静态页约定

- **引用工单**：T-001、T-002

## 约定内容

**服务**：`server.js`（T-001 实现），仅用 Node 内置模块。端口取 `PORT` 环境变量，默认 3000。数据读写复用 `todo.js` 的 `add`、`done`、`load`，沿用 `TODO_FILE`。

**静态页**：`GET /` 返回 `public/index.html`（T-002 实现），`Content-Type: text/html; charset=utf-8`。前端是单文件，JS/CSS 内联，用相对路径请求接口（`/api/...`），不引入任何外部资源或依赖。

**JSON 接口**（请求和响应均为 `application/json; charset=utf-8`）：

| 方法与路径 | 请求 | 成功响应 | 错误 |
|---|---|---|---|
| `GET /api/todos` | 无 | 200，`[{ "id": 1, "text": "x", "done": false }, ...]`（即 `load()` 的原样结果） | — |
| `POST /api/todos` | `{ "text": "buy milk" }` | 201，新建的 `{ id, text, done:false }` | text 缺失、非字符串或去空白后为空：400，`{ "error": "..." }` |
| `POST /api/todos/:id/done` | 无 body | 200，更新后的 `{ id, text, done:true }` | id 不是正整数：400；id 不存在：404；均为 `{ "error": "..." }` |

其他路径返回 404，`{ "error": "not found" }`；路径对但方法不对返回 405。文本存入前去掉首尾空白。已完成的待办再次标记完成仍返回 200（幂等）。

**前端行为**：页面加载时 `GET /api/todos` 并渲染列表；输入框加提交按钮（回车也可）调用 `POST /api/todos`；每项前有复选框，勾选未完成项时调用 `POST /api/todos/:id/done`；已完成项复选框选中且禁用（接口不支持取消完成）；接口出错时在页面上显示错误信息；渲染文本一律用 `textContent`，不用 `innerHTML` 拼用户输入。

**补充行为（T-001 实现并验收，2026-11-04 补记）**：请求体不是合法 JSON：400，`{ "error": "..." }`；请求体超过 64KB：413，`{ "error": "body too large" }`，带 `Connection: close`。
