## Contracts

`<project>/.butler/contracts/C-001.md`

## Acceptance criteria

- One self-contained file: inline CSS and JS, no build step, no external resources.
- Shows the list of todos on load (GET /api/todos); done items visibly distinct (e.g. strikethrough); empty-state message when no todos.
- Add form (text input + submit, Enter works); blank input is not sent; list refreshes after adding; input cleared.
- Each not-done todo has a "Done" button calling POST /api/todos/:id/done; list updates afterwards.
- API errors (`{"error"}` or network failure) shown to the user, not swallowed.
- Todo text rendered safely (textContent, not innerHTML) so `<script>`-style text is displayed literally.
- Uses only relative URLs per C-001. Reasonably tidy, responsive layout.
- Verified against a throwaway stub of C-001 outside the repo; report how.
